## 개요

유저가 웹사이트에 처음 진입하면 보는 페이지입니다.  
열대우림을 배경으로 게코가 강을 따라 여정을 떠나는 **스크롤 기반 단일 페이지 경험**이며, 여정이 끝나면 Flute / Marine Biology / Tennis 서브페이지로 이동할 수 있는 3개 버튼이 나타납니다.

---

## 기술 스택


| 기술                     | 용도                  |
| ---------------------- | ------------------- |
| HTML / CSS             | UI 오버레이, 로딩 화면      |
| JavaScript (ES Module) | 스크롤 진행도, 3D 씬 제어    |
| GSAP + ScrollTrigger   | 스크롤 연동 애니메이션        |
| Three.js               | 3D 열대우림, 게코, 장면 렌더링 |
